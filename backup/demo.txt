一、DeepSeek 与幻方量化的背景
幻方量化（High-Flyer）成立于2015年，是中国头部量化对冲基金之一。2023年，幻方量化成立独立的人工智能研究公司“深度求索”，正式进军大模型领域。同年11月，深度求索发布了首款开源大模型 DeepSeek Coder。2024年底至2025年初，DeepSeek 先后发布了 V3 和 R1 系列模型，其推理成本和逻辑推理能力在全球 AI 界引发轰动。DeepSeek V3 的总训练成本约为 557 万美元，但具体研发团队的完整名单并未公开。

二、RAG 技术的落地挑战
RAG（检索增强生成）通过引入外部知识库来缓解大模型幻觉，但实际落地中存在三大挑战：第一，检索精度差，返回了不相关的文档片段；第二，上下文冲突，检索到的不同文档对同一事实的描述相互矛盾；第三，大模型过度推理，上下文没写的内容，模型自行脑补。在金融、医疗等严肃场景中，一次幻觉就可能导致严重的资金损失或合规风险。

三、自动化评测的核心指标
当前业界常用 Ragas 框架来量化 RAG 系统的质量，核心指标包括：忠实度（Faithfulness），衡量回答是否完全基于检索到的上下文；上下文精度（Context Precision），衡量检索到的上下文中真正有用的比例。两者均以 0 到 1 之间的分数表示，分数越高代表质量越好。但 Ragas 的评测本身需要反复调用大模型作为裁判，耗时较长，且不同模型作为裁判时结果可能存在差异。

四、质量门禁的工程实践
在 CI/CD 流水线中，可以将评测指标与阈值绑定：当忠实度低于 0.8 时，脚本返回错误退出码，阻断模型发布；当指标达标时，则允许上线。这种做法将主观的“模型答得好不好”转变为客观的“流水线通过或阻断”，避免了劣质模型上线消耗高昂的算力与 Token 成本。但需要警惕的是，如果评测工具本身因为 API 超时或网络抖动返回了 nan，质量门禁必须能识别这种异常，而不是盲目放行。
