# Phase 3-B-10 历史诊断脚本归档

归档日期：2026-10-01。归档方式为复制，根目录原件仍保留并由 Git 忽略；本轮不删除原件。

这些文件是历史诊断快照，不属于 backend、正式运行入口或 pytest 测试集；不自动执行、不改写为测试。

- `_diag_env.py`：第三方模块导入检查。
- `_diag_refusal.py`、`_diag_refusal2.py`：历史拒答字段诊断。
- `_verify_refusal.py`：特定自动生成记录的拒答字段检查。
- `_verify_trend.py`：依赖 main 兼容层的趋势图诊断，执行会生成图表。

部分脚本包含原项目绝对路径，或依赖当时的历史数据、兼容函数与字段；本次仅原样保存，不承诺可在新路径直接运行。原路径与 SHA-256 记录见 manifest.json。
