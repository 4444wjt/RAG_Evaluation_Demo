# v1.2.0 · 逐句核对与质量门禁平台

发布日期：2026-10-13。完整变更见 [CHANGELOG](../../CHANGELOG.md)。

鉴真全域 VeriScope AI 面向 RAG 问答应用：把回答拆成逐句，对照检索原文核对依据，再由质量门禁按阈值决定能否放行。典型用法是 RAG 应用上线前把它接进 CI 当回归门禁：门禁不通过，构建失败。

## 亮点

- **中文陈述兼容层 `zh-sentence-v1`**：修复 Ragas 0.1.21 分句时只保留英文句号结尾的句子、中文句子被整句丢弃的问题；英文路径、指标公式和门禁不变。
- **门禁回放**（`scripts/gate_replay.py`）：对已归档结果离线重新执行门禁裁决，不调用模型、不需要密钥，不通过时退出码为 1，可直接接入 CI；示例工作流见 `.github/workflows/quality-gate-example.yml`。
- **门禁可信度四问**（`docs/competition/gate-credibility.md`）：从四个方面检验门禁本身——结论能否复算、换裁判会不会变、裁判是否依据证据、结论有多确定；每一问都有可离线复算的证据。
  - **独立裁判对照**：原裁判重判作噪声基线，另换 Qwen2.5-72B 对照，量化同源裁判偏差。
  - **裁判证据敏感性实验**：固定 6 条既有陈述，只改变提供给裁判的证据，两个裁判共 60 次请求；材料经作者逐条确认，付费单独授权，2026-10-12 运行一次。
  - **结论确定性分析**：对 25 题正式运行按题重抽，给出门禁指标的区间，并比较不同计算口径。
- **25 题正式运行证据**：2026-10-05 单模型运行，保留真实 FAIL（正向忠实度 0.7375，低于 0.8），完整回答、上下文、指标、Trace 和哈希均已归档。
- **人工核验存档格式**（`schemas/review-archive.v1.schema.json`）：人工意见与机器判定并列保存、互不覆盖，绑定冻结快照的 SHA-256。
- **总览首屏「正式运行回放」**：展示从逐句判定到门禁结论的计分过程，数据由冻结证据生成并校验。
- **公网演示只读**：写入类请求由 nginx 与后端两层拦截（HTTP 423）。
- **跨平台哈希修复**：新增 `.gitattributes`，按记录逐文件固定检出换行符；Linux CI 上的完整性哈希校验恢复通过。
- **治理**：新增 SECURITY.md、Issue 与 PR 模板。

## 已知限制

- 正式运行只覆盖同一份《存款保险条例》节选的 25 题固定场景，不是跨领域 Benchmark。
- 人工核验由作者本人完成，不是独立复核；所有结果不作为总体准确率。
- 敏感性实验只有 6 条定向陈述，不代表统计独立样本。
- 公网演示站为只读部署；在线评测需本地配置模型密钥后运行。
- 项目目前为单人维护。
