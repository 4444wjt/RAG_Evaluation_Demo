# 裁判判错校准：把裁判误差也算进门禁区间

门禁可信度第四问（[这个 FAIL 有多确定](../gate-credibility.md)）给出的区间只计题目抽样，把每一条逐句判定都当作正确。门禁的正向忠实度来自 Ragas 裁判对 52 条陈述的逐条判定；裁判会判错，真实区间应当同时计入「题目抽样」和「裁判判错」两类不确定性。

本目录给出这样的区间：方法与代码、模拟检验、不需要标注的敏感性分析，以及请非作者人工标注的整套材料。门禁规则与已记录的 FAIL 都不改。

## 不标注也能看出的：结论取决于几条判定

裁判判定 52 条陈述中 43 条为支持，门禁口径（按题平均，拒答按 0 计）为 73.8%，低于门槛 80%。

**最少改判几条，FAIL 会变成 PASS？**

- 作答的 16 题里，判为不支持的陈述只有 5 条。要把它们全部改判为支持，均值才恰好到 80.0%：
  - D01 第 1 条：建立存款保险制度的目的是为了建立和规范存款保险制度。
  - D09 第 1 条：投保机构应当交纳的保费按照本投保机构的被保险存款计算。
  - C02 第 2、5、6 条：「合计51万元」「超出部分为1万元」「超出的1万元依法从清算财产中受偿」。这三条的数字来自题目条件，资料里没有。
- 4 道拒答题各只有一条陈述（英文的「资料中没有答案」），改判其中任意 2 条也能翻转。作者／AI 既有分析认为资料包含纠正前提的依据，因此原不支持判定有可解释依据；这不是本轮待完成的非作者标注结论。

**裁判误差落在什么范围，结论会翻转？**

裁判口径的期望值是 E[Ĝ] = (q0 + q1 − 1)·θ + (1 − q0)。其中 θ 是人工口径下的门禁指标，q1 是灵敏度（真支持判为支持的概率），q0 是特异度（真不支持判为不支持的概率）。由此可以解出：

| 裁判特异度 q0 | 灵敏度低于此值时，校正后的点估计达到 80% |
|---|---|
| 1.00 | 0.922 |
| 0.95 | 0.909 |
| 0.90 | 0.897 |

也就是说，只要裁判漏判 8% 以上真支持的陈述，这次 FAIL 就可能是裁判造成的。逐句核对在 ANAH 上测得的灵敏度是 0.727（见 [外部基准验证](../external-validation/README.md)）。但门禁用的是 Ragas 的另一套提示词，这个数字不能直接套用；门禁裁判的误差只能靠人工标注来估计。

## 方法

三种做法，都在 [`judge_error.py`](../../../backend/core/judge_error.py) 中实现。

**① 校准校正（[Lee et al., ICML 2026](https://proceedings.mlr.press/v306/lee26bl.html)，arXiv 2511.21140）**

- 用一批人工标注的陈述估计裁判的灵敏度 q̂1 与特异度 q̂0，再用 Rogan–Gladen 校正点估计：θ̂ = (Ĝ + q̂0 − 1) / (q̂0 + q̂1 − 1)。
- 区间用原文式 8–12 的调整 Wald 区间，同时计入测试样本与校准样本两部分的抽样误差。
- 前提有两条：
  - 裁判好于随机（q0 + q1 > 1）；
  - 校准时与使用时的裁判判定不变：同一裁判模型、同一提示词、同一领域。

**本项目的推广：按题聚集的有效样本量。** 原方法假设测试样本相互独立，而门禁的 52 条陈述分属 20 道题，同一题的陈述高度相关。所以把测试样本量换成按题方差折算的有效样本量：

n_eff = Ĝ(1 − Ĝ) / Var_q(Ĝ)

其中 Var_q 由逐题占比的样本方差除以题数得到，这与 Korn & Graubard（Survey Methodology, 1998）用有效样本量处理聚集抽样的思路相同。本次 n_eff ≈ 23.1，即 52 条陈述只相当于约 23 条独立陈述。

**② 预测驱动推断（PPI，[Angelopoulos et al., Science 2023](https://doi.org/10.1126/science.adi6000)）**

只人工标注部分题目时使用：

- 未标注题用裁判值；
- 已标注题用「人工 − 裁判」的差做校正；
- 两组题互不重叠。

PPI 不要求裁判误差率固定或已知，但仍要求标注来自同一次运行，且已标注的题具有随机抽样基础。标注页的题目顺序已用固定种子打乱，只用「从 Q01 起连续标完」的题；本批标注题数须在查看标签和分析结果前确定，不能根据题目难度或结果决定停止。跳着标完的题不计入。连续标完的题少于 10 题（仅为已模拟的规模，不保证 95% 覆盖），或未标完的题少于 2 题时，不给区间；优先标完全部 20 题。

**③ 全部人工标注**

52 条全部标注时，人工口径直接替代裁判，区间只剩题目抽样误差。区间用有效样本量代入 Agresti–Coull 区间，它正是 ① 在裁判完全正确时的特例。

三态解读与第四问相同：

- 区间下限也达到门槛：确定通过；
- 区间上限仍低于门槛：确定不通过；
- 其余：证据不足。

## 模拟检验

[`judge_error_simulation.py`](../../../tools/competition/judge_error_simulation.py) 按正式运行的题目结构，比较五种区间的实际覆盖率。题目结构是 20 题、各题陈述数与正式运行相同，共 52 句。

**设定：**

- 真实指标 θ ∈ {0.7, 0.8, 0.9}，分别低于、等于、高于门槛。
- 各题支持率服从 Beta 分布，题间集中度取两种：
  - c = 0.4，由正式运行的题间方差按矩估计得到（0.396）；
  - c = 4，题间差异较小，作对照。
- 裁判误差取 ANAH 实测值：灵敏度 72/99，特异度 178/200。
- 校准样本 (m0, m1) 取 (10, 40) 与 (50, 50)，前者约等于人工标注这 52 条能得到的规模。
- 裁判有两种情形：「判定不变」，以及「判定漂移」（使用时的灵敏度比校准时低 0.1）。
- 共 24 种设定，每种模拟 2000 次，固定种子，可重算。

| 95% 区间的实际覆盖率 | 判定不变 | 判定漂移 |
|---|---|---|
| 只计题目抽样（把判定都当作正确） | 3.3%–52.7% | 0.1%–20.9% |
| 校准校正·独立（陈述当作独立样本） | 90.5%–93.7% | 76.2%–82.4% |
| **校准校正·聚集（本项目）** | **94.4%–96.0%** | 81.7%–88.8% |
| PPI（随机标注 10 题） | 92.6%–94.1% | 92.6%–94.7% |
| 全部人工标注 | 90.3%–96.6% | 90.1%–96.0% |

1. **只计题目抽样会严重失准。** 裁判有这样的误差时，真实值 90%（达标）的系统有 48%–50% 的模拟被判为「确定不通过」。
2. **按题聚集是必要的。** 把陈述当作独立样本，覆盖率在 90.5%–93.7%，偏窄；按题折算有效样本量后回到 94.4%–96.0%。
3. **校准校正依赖「裁判不变」。** 判定漂移时它会失准；同一次运行的人工标注（PPI 或全部标注）不受影响。所以本次运行采用全部标注；以后的运行，只有在裁判模型、提示词与领域都不变时，才复用本次标注得到的校准值。
4. **代价是区间变宽。** 校正后的区间宽度约 0.39–0.69，大多落在「证据不足」。20 道题本身就难以确定达标：即使全部人工标注、真实值 90%，也只有 18%–32% 的模拟能判为「确定通过」。

模拟只说明方法在这些设定下的表现。裁判误差借用了 ANAH 上的实测值，不代表门禁裁判的真实误差。

## 标注说明（给标注人）

**谁可以标注：** 没有参与本项目的开发，也没有编写题目和参考答案的人。不需要金融或法律背景。

**怎么标：**

1. 打开工作台的「人工标注」页（`#/lab/annotate`）。公开站点为 https://4444wjt.github.io/RAG_Evaluation_Demo/ ，本页随下次部署上线。
2. 填写代号（不必是真名），并勾选「我没有参与本项目的开发，也没有编写题目和参考答案」。
3. 逐条阅读「资料」和「陈述」，选择一个标签：
   - 数字键 1：**支持**，仅凭资料就能读出或直接推出；
   - 数字键 2：**矛盾**，资料中有与之相反的内容；
   - 数字键 3：**无依据**，资料中既没有支持，也没有相反的内容；
   - 数字键 4：**无法判断**，陈述含义不清，或拿不准（尽量少用）。
4. 共 52 条（20 题），约 30 分钟，优先全部完成。进度自动保存在本浏览器中；换浏览器继续时，先导入已导出的文件。需要分几次完成时，请提前确定本批题数，并从第一条起按顺序往下标。
5. 标完后点「导出标注文件」，把文件交给作者。

**判断规则：**

1. 只依据「资料」判断。题目只用来理解陈述在说什么，题目里给出的数字和情形不算依据。
2. 不用自己的知识：即使你知道陈述是对的，资料里没有也判「无依据」。
3. 陈述的每一部分都要有依据，包括条号、数字、主体和范围：有一处与资料相反判「矛盾」，有一处找不到判「无依据」。
4. 「根据提供的文档」「根据参考资料」这类开头不影响判断；英文陈述按意思判断。
5. 陈述说「资料中没有答案」时：资料里确实没有相关内容才判「支持」，资料里有就判「矛盾」。
6. 资料片段可能在句中截断，只按显示出来的文字判断。
7. 内容只来自题目条件（例如题目给出的金额）时，判「无依据」，并勾选「内容来自题目」。

这些规则与 Ragas 忠实度的定义一致：陈述能否仅由检索资料推出。

**请保持独立：**

- 标完之前，不要查看本仓库的评测证据、门禁审计页或其他标注人的结果；
- 两位标注人之间不要讨论。

标注页本身不显示裁判的判定、原题号、回答与参考答案。

## 分析（给作者）

```bash
python tools/competition/judge_calibration.py status
python tools/competition/judge_calibration.py analyze --annotations <标注人A.json> <标注人B.json> --output docs/competition/judge-calibration/<日期>-annotation
```

**分析口径（事先约定，标注前写定）：**

- **分母与门禁一致。** 每题的人工值 = 人工判为支持的陈述数 ÷ 该题陈述总数，再按题平均，与门禁口径相同。任何陈述都不从分母中剔除。
- **已定与未决。** 只区分支持与否：两人都判支持，或都判不支持（矛盾、无依据都算不支持），为已定。两人不一致，或任一人选了「无法判断」，为未决。
- **未决陈述只给点估计边界，不剔除。** 剔除会改变该题的分母，使人工口径与门禁口径不可比。未决陈述按「全部算不支持」「全部算支持」计算点估计上下界；这个范围不是置信区间。区间宽度会随未决标签的混合赋值变化，两个端点区间不能保证包住所有情况。因此，只要进入分析的陈述仍有未决，工具不输出 95% 区间及区间三态，明确写出原因。两个点估计落在门槛两侧时，不下点估计结论；无未决时才使用既有区间方法。
- **部分标注的限制。** 本批题数在标注前确定。未标完全部题目时，只用从 Q01 起连续标完的题做 PPI，且至少 10 题、未标完的题至少 2 题，否则不给区间并写明原因；达到数量条件也不等于保证覆盖率。两位标注人时，一题要两人都标完才算标完。
- **灵敏度与特异度只作描述。** 它们只用已定的陈述计算，写入 `calibration.json` 供以后的运行使用，不参与本次区间。
- **一致性。** 报告原始一致率与 Cohen's κ：四类标签算一次，只分支持与否再算一次。只有一位标注人时，没有一致性指标，结论须注明是单人标注。

**输出：**

- `analysis.json`：
  - 每条陈述的人工标签与裁判判定；
  - 裁判的灵敏度、特异度及 Wilson 区间；
  - 逐题的陈述数、裁判值与人工值的上下界；
  - 人工口径的门禁指标：估计方法和点估计边界；无未决时报告区间与三态解读，有未决时 `interval` 与 `state` 为 `null`，并写明不给区间的原因。
- `calibration.json`：供以后的运行做校准校正（方法 ①），只在同一裁判模型、同一提示词、同一领域时适用。

无论结果是确定通过、证据不足还是确定不通过，都如实报告；已记录的 FAIL 不改判。
