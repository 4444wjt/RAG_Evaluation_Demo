恢复此项先补齐以下证据，不需要重新设计实验：

材料齐备后才计算数据文件 SHA-256，并按已批准方案固定中文问答 40 条（无幻觉 / 含幻觉各 20 条，种子 `20261013`）。不足数量、字段无法映射或入选上下文超过模型上限时停止报告，不截断原文、不依据结果换题。

## 保留的实验边界

后续目标仍为**现有 Trace 在无参考答案输入条件下的外部子集验证**：复用问题、回答和完整上下文，`ground_truth` 传空字符串；标签、正确答案和扰动说明不得进入裁判提示。只运行 Trace，不重新检索、生成回答或运行五项指标。

[论文附录](https://arxiv.org/html/2502.19209v1) 将基准 PASS / FAIL 对应为无幻觉 / 含幻觉（中文示例也使用“通过 / 失败”）。实际下载文件仍需确认其具体表示。这些标签与本项目 Quality Gate 的 PASS / FAIL 分开；含合成扰动的数据标签不能统称独立人工核验结果。

后续调用上限仍为单裁判 40 次，前 4 条包含在内；无自动重试、模型切换或补跑。材料确认和单独付费授权齐备后才允许执行。空 Trace、过滤或解析异常单列“无法判定”，不能按无幻觉计分；“未检出幻觉”也不证明陈述抽取完整或回答完全正确。
