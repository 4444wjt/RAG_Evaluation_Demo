# 鉴真全域 VeriScope AI 作品介绍

> AI 测试交付与质量门禁平台

材料日期：2026-10-05。已完成工作与本轮新实验的状态分别说明。

## 项目解决的问题

AI 应用上线前，可靠性判断往往停在「一个平均分」或「肉眼抽查」，缺少一套可交付、可复用的测试结论。鉴真全域 VeriScope AI 面向 AI 应用（当前以 RAG 问答为测试对象）的测试交付，把测试用例集、检索上下文、模型回答、逐句断言、多模型指标、Quality Gate 和人工复核汇集到中文工作台，帮助使用者把「回答是否可信」变成「用例 → 断言 → 门禁 → 报告 → 复核」可逐条回查的测试结论。

## 与「AI 增强测试交付平台」方向的对应

本项目归属于「AI 测试交付平台」这一品类，核心链路与测试交付的五个环节逐条对应：

| 测试交付环节 | 本项目实现 |
|---|---|
| 测试用例集 | 自动出题、自定义测试集、TruthfulQA 入口（`backend/services/testsets.py`） |
| 断言结果 | 逐句溯源：有依据／事实错误／无依据编造，含证据与检索原文 |
| 质量门禁 | Quality Gate，默认阈值 0.8，按首个有效评测模型判定 |
| 报告导出 | CSV / HTML / Excel / PDF / 图表 |
| 人工复核 | 评测验证模块，核验材料绑定冻结快照与 SHA-256 |

## 已完成的产品

- 评测总览、TraceView、多模型对比、幻觉分析、评测报告与真实评测工作区。
- 文档处理、检索、模型问答、Ragas 指标、逐句溯源及报告生成的后端流程；保留 CLI、Gradio 和 FastAPI 本地入口。
- Quality Gate 展示与真实历史金融 FAIL 案例；说明样本范围、保存指标和门槛。
- 评测验证模块：人工结论与机器原判定分别呈现，核验材料绑定冻结快照版本与 SHA-256。

项目使用 React、FastAPI、LangChain、Chroma、Ragas 和已有模型服务。项目贡献集中在评测流程整合、中文证据回查、结果解释与人工核验记录；相关第三方组件和依赖按各自许可使用。

## 可以展示的现有证据

无密钥演示使用冻结快照 `20260930-1958`：6 个独立问题、3 个模型、18 条回答。作者 Kk 于 2026-10-05 逐条检查其中 13 条定向记录，结果为一致 3 条、存在分歧 5 条、无法确认 5 条。AI 仅辅助整理材料与定位证据，作者确认正式结论。

核验覆盖完整回答、参考答案、检索上下文、机器 Trace 和引用关系，记录抽取遗漏、拒答标签争议及证据不足。13 条是定向检查的回答记录数，不能据此计算总体准确率。历史金融 FAIL 来自另一场旧 CLI 运行，其正向上下文精度 0.7778 低于 0.8 门槛；该案例与当前 Demo 分开保存。

前端依赖准备后，已有快照可以在本地无需模型密钥、Embedding 或后端展示，不产生模型调用费用。真实评测需要另行配置环境和凭据，并产生提供方调用费用。

## 当前技术限制

当前后端会将相应被测模型用于 Ragas 评测与 Trace 判定，存在生成与裁判同源的偏差，即 self-Judge 限制。人工核验有助于暴露分歧，但作者自审没有替代独立复核。历史快照还缺少确切裁判版本、提示词版本和完整环境记录。

PASS 只说明指定样本达到保存门槛；默认 0.8 尚无业务校准证明。空 Trace 或缺失指标不能作为无幻觉证明。当前服务定位为本地评测与展示，真实评测采用同步请求，尚无生产所需的完整长任务管理和访问隔离。

## 本轮运行与待完成事项

2026-10-05 已通过当前 Web API 完成一次25题单模型正式运行，使用同一《存款保险条例》节选的固定案例集。请求 `deepseek-chat`，实际返回 `deepseek-flash`；Ragas 0.1.21、`zh-sentence-v1`，325次完整调用、558,958 token。25条回答和五项指标均完整归档，Trace非空18条、空7条。正向 Faithfulness 0.7375 低于0.8，正向 Context Precision 0.9833 达到0.8，因此原始 Quality Gate 保留 FAIL。

[正式运行公开证据](evidence/20261005T144504Z-full-39511424/README.md)包含输入、请求/响应、用量、指标、Trace、报告、运行源码和重新计算的哈希；[离线分析表](evidence/20261005T144504Z-full-39511424/analysis.md)仅为 AI 辅助分析、待人工确认，不会更新 `credibility-review.json`。旧冻结 Demo 的13条作者核验仍只绑定旧快照。

本实验是单一金融材料的25题固定场景，部分题目共享法条，不是跨领域 Benchmark、统计独立样本或总体准确率证明。F类拒答、C02/D09指标与Trace差异、C03/D08低分和N03/N05拒答Trace差异均保留为可回查观察，原因未确认处不作推断。Trace和人工意见不直接触发当前门禁。

无密钥前端演示、真实 Web API 运行和旧快照模型复跑是不同证据；本轮没有新增模型调用授权。
