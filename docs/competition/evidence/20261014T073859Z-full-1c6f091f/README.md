### 回归对比

基线对比认定正向忠实度「未退步」，逐题平均变化 `+0.1232`；上下文精度变化 `0`。下降幅度最大的是 D08，`1.0 → 0.33`：
- 两次的回答几乎相同（「存款保险费率由基准费率和风险差别费率两部分构成」）。
- 本次逐句核对给出的判定是 1 条陈述、有原文依据。
- 所以这次下降应归为 Ragas 裁判的波动，而不是回答变差。回归对比把它列为提示项，没有据此拦截。

另外，负向题的上下文精度从 0.4 变为 0.0。检索参数没有变；负向题本身没有可对照的参考答案，而这一项不参与门禁。原因未核实，这里只如实记录。

## 不能说明什么

- **修复是在发现问题的同一批 25 题上验证的。** 这批题已经暴露了问题，所以在同一批题上通过，不代表在新题上也有同样效果。要排除对题集的过拟合，需要另出一批错误前提题，本次没有做。
- 只有一个领域、一个模型、一次运行。Ragas 裁判有波动（见 D08），`0.8607` 与阈值 `0.8` 的差距只有 `0.06` 左右，再跑一次结果可能不同。
- 只证明了新增这一句的效果，没有比较其他写法。
- 逐题分析尚未人工确认。
