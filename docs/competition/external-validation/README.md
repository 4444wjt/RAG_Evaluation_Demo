# 外部基准验证：逐句核对对照公开人工标注

逐句核对（`backend/services/trace.py`）是平台的核心功能：把回答拆成原子陈述，逐条判定「原文支持 / 与原文矛盾 / 原文无依据」，并给出原文证据。本目录用两个公开、带人工标注的中文数据集，检验这个核对本身准不准，并在法规以外的新闻领域做一次体检。

注意：门禁分数（正向忠实度）来自 Ragas 忠实度指标自己的逐条判定，与逐句核对是两次独立调用（同一模型，不同提示词）。本实验检验的是逐句核对，不能直接推到门禁用的那套判定上；后者的检验见 [裁判判错校准](../judge-calibration/README.md)。

## 方法

**① ANAH：逐句核对对照人工标注（300 次请求）**

- 取中文部分。只用参考文档合计不超过 12,000 字的主题（192 / 286 个）。
- 标签只认单一的「无 / 矛盾 / 无法验证」。`<无事实>` 和标签后夹带解释的标注一律跳过，不猜。
- 标注写了原句（`<要点>`）就直接用。没写原句的，按句末标点切分回答后，按句序对齐取句；句数对不上的整段跳过。在两种都有的标注上核对过：两者只差列表序号与空白。
- 抽样：固定种子 20261013，每类各抽 100 句；同一主题最多 2 句，最终覆盖 174 个主题。
- 核对方式：把单句作为回答，主题参考文档作为上下文，问题照原样给出，不给参考答案。
- 标签映射：
  - 任一陈述判为「矛盾」，记为矛盾；
  - 否则任一陈述判为「无依据」，记为无法验证；
  - 全部「支持」，记为无幻觉。
- 二分类口径：把「矛盾」和「无法验证」都算作有幻觉，即只区分「支持」与「不支持」，与忠实度这类指标的口径相同。

**② RGB：新闻领域三种证据条件（200 次请求）**

| 条件 | 题数 | 给模型的资料 | 检验什么 |
|---|---|---|---|
| 噪声 | 40 | 3 篇相关 + 2 篇无关 | 正确回答会不会被误判 |
| 应拒答 | 40 | 5 篇无关 | 资料里没有答案时是否拒答 |
| 反事实 | 20 | 含错误事实的相关资料 + 2 篇无关 | 资料本身错了，核对能否发现 |

每题先用生产问答提示 `rag_answer` 作答，再用 `trace_hallucinations` 核对。正确与否按 RGB 官方规则判定：每个要点的任一写法出现在回答中即算答对。

## 结果

### ① ANAH：300 句

99.7% 的句子产出了可用陈述：297 句完全通过引用校验，2 句部分通过，1 句模型未拆出陈述。

| 人工标注 ＼ 核对结果 | 无幻觉 | 矛盾 | 无依据 | 未产出陈述 |
|---|---|---|---|---|
| 无（100） | **72** | 2 | 25 | 1 |
| 矛盾（100） | 13 | **49** | 38 | 0 |
| 无法验证（100） | 9 | 6 | **85** | 0 |

| 二分类（有无幻觉） | 值 | 95% Wilson 区间 |
|---|---|---|
| 召回率：有幻觉的句子被标出 | 0.890（178 / 200） | 0.839–0.926 |
| 精确率：标出的句子确有幻觉 | 0.868（178 / 205） | 0.815–0.908 |
| 特异度：无幻觉的句子未被标出 | 0.727（72 / 99） | 0.632–0.805 |
| F1 | 0.879 | — |
| 平衡准确率 | 0.809 | — |

- **等量抽样会抬高精确率。** 样本按类别等量抽取，精确率要折算才能用于实际分布。可抽样的 2,502 句中，有幻觉的占 43.8%（无 1,406、矛盾 531、无法验证 565）。按召回率与特异度折算，精确率约 0.72，计算方法是：召回率 × 患病率 ÷（召回率 × 患病率 ＋（1 − 特异度）×（1 − 患病率））。召回率与特异度不受抽样比例影响。
- **两种取句方式结果相近。** 直接取原句的 47 句：平衡准确率 0.878；按句序对齐的 253 句：0.795。前者样本量小，区间较宽。

### ② RGB：100 题

| 条件 | 结果 |
|---|---|
| 噪声（40） | 40 题全部答对（RGB 规则），无拒答。逐句核对把 0 / 40 个正确回答误判为有幻觉 |
| 应拒答（40） | 35 题拒答（87.5%，区间 73.9%–94.5%）。作答的 5 题中，4 题只复述资料内容，判为有依据；其中「春运首日车票何时开售」一题，资料里其实有能推出答案的片段。逐句核对标出了另 1 题中模型自行推出的结论（把「文心大模型 ERNIE」当作答案） |
| 反事实（20） | 3 题拒答，17 题作答，见下 |

反事实条件下 17 题作答的回答，按字符串分为三类：

- 只给出错误答案、没有提到正确答案：11 题。逐句核对只标出其中 3 题。
  - 2 题判为「矛盾」，因为同一批资料里另有片段与错误答案矛盾；
  - 1 题判为「无依据」，因为模型自行加了「原文应为笔误」的说法。
  - 其余 8 题判为「支持」：回答里的错误事实都能在资料中逐字找到。其中 2 题模型已指出资料前后矛盾，但给出的说法仍出自资料。
- 同时出现错误与正确答案：5 题。其中 2 题是数据本身的特例：一题错误答案与正确答案相同，另一题「12.3%」包含「2.3%」。其余 3 题是模型指出资料矛盾，或把两种说法并列。
- 只给出正确答案：1 题。

## 解读与局限

1. **能发现大多数幻觉。** 在人工标注为有幻觉的句子上，召回率 0.89。「矛盾」类被标出 87%（49 + 38），其中 38 句被判为「无依据」而不是「矛盾」：参考文档没有直接写出相反事实时，核对倾向于判「无依据」。只区分支持与否时，这种细分差异不影响结果。
2. **比人工标注更严。** 人工判为无幻觉的句子中，有 27% 被判为「无依据」。这类句子多是概括、评价性的表述（例如某场战斗「振奋了全国军民的信心」），参考文档没有逐字支持。也就是说，逐句核对宁可多标，不放过无依据的内容。
3. **在新闻领域没有误伤正确回答。** RGB 噪声条件下 40 个正确回答全部判为有依据。应拒答条件下拒答率 87.5%：问答提示的拒答出口在跨领域时仍然有效。
4. **查不出资料本身的错误。** 这是忠实度核对的固有边界：它检查回答与证据是否一致，不检查证据是否正确。资料写错时，照抄的回答会被判为有依据（8 / 11）。要发现这类问题，需要另行检查资料来源的可信度，不能指望逐句核对。
5. **范围有限。**
   - ANAH 只用了文档不超过 12,000 字的主题，单句脱离上下文核对，代词指代可能变得模糊。
   - RGB 只抽了 100 题。
   - 只用了一个裁判模型（服务端返回 `deepseek-flash`）。
   - 每个请求只运行一次，没有重复测量。

## 复现

先按上表版本下载源文件到 `work/external/anah/*.jsonl` 和 `work/external/rgb/zh_{refine,fact}.json`，工具会核对哈希。

```bash
python tools/competition/external_validation.py prepare   --dir work/competition/external-validation/<新目录>
python tools/competition/external_validation.py authorize --dir work/competition/external-validation/<新目录> --by <授权人> --budget <元>
python tools/competition/external_validation.py run       --dir work/competition/external-validation/<新目录>
python tools/competition/external_validation.py analyze   --dir work/competition/external-validation/<新目录> --output <归档目录>
```

- `prepare` 不调用模型。同一版本的源文件与种子会生成相同的样本，本次样本包的 SHA-256 为 `a5a8d597…351a65`，与 `authorization.json` 中记录的一致。
- `run` 运行前检查三件事：授权存在，样本包未变，工具、逐句核对与问答提示的代码未变。达到请求上限或预算即停止；中断后续跑，不会重复付费。
- 工具的离线测试见 `tests/test_external_validation.py`，测试不调用模型，也不需要下载数据。

`SHA256SUMS.txt` 记录本目录各文件的哈希。工作台「门禁审计」页的数据生成时会核对这些哈希，并用 `items.json` 重新计算 `summary.json` 中的指标，对不上就拒绝生成。
