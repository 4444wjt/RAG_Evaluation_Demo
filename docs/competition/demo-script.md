# 三分钟比赛演示脚本

本脚本展示冻结 Demo `20260930-1958` 与独立的历史金融 FAIL。旧版本和`zh-sentence-v1`修复后各有一次5题历史验证；2026-10-05已完成25题单模型正式运行，作为真实证据主线。

## 演示准备

在 `frontend/` 安装依赖并启动前端，打开 `http://127.0.0.1:5173/`，点击“查看演示”；也可直接进入 `http://127.0.0.1:5173/#/lab/demo`。

```powershell
npm ci
npm run dev
```

依赖安装可能需要联网。依赖准备后，展示已有快照无需模型密钥、Embedding 或后端，不产生模型调用费用。后端健康检查失败的提示不影响快照。演示过程中只查看已有材料，真实模型调用安排在独立实验中。

## 三分钟流程

| 时间 | 画面与动作 | 讲述要点 |
|---|---|---|
| 0:00–0:20 | 首页，点击“查看演示” | “RAG 检索到文档之后，回答仍可能缺少依据。这个工作台把回答、检索材料、逐句判断和质量门禁放在一起，方便回查。接下来展示已有评测的冻结快照。” |
| 0:20–0:45 | 评测总览，指出模型、范围和门槛 | “快照有 6 个问题、3 个模型、18 条回答。当前门禁卡检查所选模型的 3 条正向用例，两项门槛都是 0.8。PASS 表示这个范围达到规则要求。” |
| 0:45–1:15 | 幻觉分析，打开融资金额的逐句记录 | “这里保留完整回答和检索原文。机器抽取了融资金额这条陈述，我们可以核对引用是否支持它，也可以检查回答中还有哪些事实未被抽取。” |
| 1:15–1:55 | 评测验证，展开一条分歧记录 | “作者已逐条核验 13 条定向记录：一致 3、分歧 5、无法确认 5。材料不足的拒答被机器标为编造，就需要保留人工分歧。AI 只辅助整理，作者确认结论；这些数字不作为准确率。” |
| 1:55–2:25 | 展开历史金融 FAIL，指出指标与门槛 | “这是真实历史运行：正向忠实度达标，上下文精度 0.7778 低于 0.8，原始门禁是 FAIL。它展示指标与规则的关系。这份记录来自旧 CLI，没有完整 Trace。” |
| 2:25–2:45 | 多模型对比，查看指标与耗时 | “三个模型共用题集，可以比较指标与耗时。平均分帮助发现差异，具体问题仍回到回答与证据核对。” |
| 2:45–3:00 | 展示工作区配置，结束 | “配置文档、固定题集、模型和阈值后，可以运行真实评测并生成报告。当前流程存在同源裁判偏差。页面演示不调用模型，真实验证会单独保留配置、结果与完整产物。” |

机器原判定与作者核验意见均按现有材料展示。历史金融 FAIL 的指标对照不能补写缺失的原始门禁说明，也不证明当前 API 已完成复跑。

## 当前 API 新实验的补充展示

三分钟演示后依次打开[旧版5题预跑](evidence/20261005T101847Z-pilot-c72cb679/README.md)和[修复后5题分析](evidence/20261005T131353Z-pilot-35f623cb/README.md)，说明两轮各自的版本、输入、token、逐题结果及报告。修复后只证明中文句子输入进入指标提示及归档完整，不表示五题全部正确；25题正式运行另有独立归档。

补充说明中文抽取问题及保留旧分数的处理：`zh-sentence-v1` 只做句子输入兼容，旧分数和修复后分数分别保留。D06、C02回答发生变化，C05在回答和上下文相同的情况下也有指标变化，不能把所有差异归因于兼容修复。最终验收状态见[验收记录](validation.md)。

新模型运行可能得到不同分数，复现目标是明确输入、配置和结果出处。新增结果的人工核验状态按实际记录呈现，已有 13 条作者核验不会自动覆盖新结果。

评测报告页需手动导入本地 HTML。仅展示已确认属于对应运行的报告；文件尚未准备时，说明入口能力即可。

## 现场故障处理

- 首页入口不可用时，直接打开 `/#/lab/demo`；服务不可用时，使用已提前检查的本地演示材料，并说明材料日期。
- 后端未启动时继续展示冻结快照。网络异常时暂停真实评测；请求断开不能视为模型任务已经取消。
- 视频、截图和快照展示均说明来源，演示画面不作为模型复跑成功的证据。

结果解释及当前未验证事项见 [可信度说明](../evaluation-credibility.md)。


## 25题正式运行主线（约60秒）

1. 打开[正式运行证据](evidence/20261005T144504Z-full-39511424/README.md)，先说明这是同一金融材料的25题固定场景，不是跨领域 Benchmark。
2. 展示请求模型 `deepseek-chat` 与实际返回模型 `deepseek-flash`、Ragas 0.1.21、`zh-sentence-v1`、325次调用和558,958 token。
3. 展示原始 FAIL：正向 Faithfulness 0.7375 低于0.8；正向 Context Precision 0.9833 达标。强调不调阈值、不把Trace争议直接当作门禁原因。
4. 展示F01/F03/F04/F05拒答、C02/D09指标与Trace差异、C03/D08低分、N03/N05拒答Trace差异；说明离线解释均为“AI辅助分析、待人工确认”。
5. 结尾说明费用仍是估算，没有自动封顶；本次没有扩展三模型或追加调用。
