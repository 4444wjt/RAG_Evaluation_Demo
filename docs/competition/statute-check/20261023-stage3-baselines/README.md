## 两条错误和一条错误回指

3. 错引第三项的变体虽然检出，best仍错误指向第二项。12个额外检出里，11个best与登记来源一致，1个不一致；这是事后来源回指核对，不是新独立验证。
所以不能把不设最低覆盖与差值的X直接复制成高置信error规则，也不能用词面排序证明语义归属。

## 是否调整规则
本轮决定：**不改当前R，不放宽0.6/0.25，不删除交叉引用豁免，不直接合并X，不实现新规则版本。**
- 项级内容归属是明确工程缺口，值得作为另一个候选版本评估；先复用已有并行扩展，区分确定错误、疑似错引与无法定位，分别报告检出、误报和回指正确性。
- 这批材料已经暴露，只能用于开发/回归。若以后实施新版本，须另存源码与版本标识、绑定新哈希，在另行锁定且未用于开发的法规/底稿上验证；本轮不为追齐12条降低标准。
- 原规则、原材料、门禁口径与历史结果均不改。只给外层运行器另起版本而替换同一路径源码，也会使原包严格校验失败；应并存原源码快照，不能重写旧包哈希。
