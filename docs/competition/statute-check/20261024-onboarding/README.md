## 工具边界
在这部没用过的法规上，发现三处锁定工具查不出来的输入问题，锁定代码没改：
- **半角项号「(一)」**：2019 年版 docx 的节选内有 11 处，解析器会把项当成款。2024 年版本身是全角，这次运行没用上。
- **BOM**：节选检查全部通过，请求会带上。核对脚本里去掉并报出。
- **U+2060（WORD JOINER）**：从 Word 粘贴带入 9 个，节选检查全部通过。作者发现后用清理脚本去掉。

运行用的节选在出题前和运行后各查过一次：无 BOM、CR 0、U+2060 0、半角项号 0。
